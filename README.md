# The Persistent Vulnerability: Characterizing Metadata Leakage in DNS over QUIC

This repository contains the source code, feature extraction pipeline, and evaluation scripts for the paper: **"The Persistent Vulnerability: Characterizing Metadata Leakage in DNS over QUIC"** (DOI: XXX-XXX).

The project introduces an early-stage website fingerprinting (WF) framework designed to analyze the structural traffic patterns of DNS over QUIC (DoQ) connections. By monitoring only the initial traffic bursts (the first 200–250 ms), the framework demonstrates that protocol-layer optimizations can inadvertently leak domain identities before a standard web page finish loading.
